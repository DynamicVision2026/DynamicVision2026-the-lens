# Lens Snap — YouTube Shorts 台本（3本）

Format: 9:16, 30–40 s, synthetic voice (VOICEVOX). Each script opens on the pain and closes on the waitlist.

Notes for production:
- The **narration** column is written for VOICEVOX: product name in katakana (レンズスナップ), ○✕ spelled マル／バツ, no symbols. The **on-screen text** column uses the normal written forms (Lens Snap, ○✕).
- Narration lengths are ~170–200 characters, about 32–38 s at VOICEVOX default speed (1.0). If a script runs long, set speed to 1.05–1.1 rather than cutting lines.
- Visuals: hands, desks, worksheets and phone screens only. No faces, no child's name visible on any paper (use the synthetic pages in `fixtures/photos/` or blank them).
- No score claims anywhere (title, text, voice). Only "time saved" and "knowing what to do".
- CTA points to the link on the channel page. Waitlist URL in descriptions: https://snap.domo-ai.com/?src=yt (the `src` tag lets us count signups from Shorts).

## Short 1 — 親のテスト前の夜（parent's night）

**Hook (0–3 s):** テスト前の夜、「何やればいい？」に答えられますか。

| Time | Visual | On-screen text | Narration (VOICEVOX) |
|---|---|---|---|
| 0–3 s | Dark kitchen table, 21:30 clock, a child's hand holding a pencil, waiting | テスト前の夜<br>「何やればいい？」 | テスト前の夜、「何やればいい？」に、答えられますか。 |
| 3–10 s | Parent's hands flipping through a stack of papers, a drawer opening | テストはどこ？<br>ドリルは全部やり直し？ | 返ってきたテストは、どこかへしまったまま。ドリルを最初から全部やるには、時間が足りません。 |
| 10–22 s | Phone camera over a worksheet → problems appear as cards with unit chips and ○✕ | 撮るだけ<br>単元ごとに自動で整理<br>先生の○✕もそのまま | レンズスナップなら、宿題やドリル、返ってきたテストを撮っておくだけ。問題ごとに単元へ整理して、先生のマルバツも、そのまま記録します。 |
| 22–30 s | Tap test range (2–3 units) → list of ✕ problems | テスト範囲を選ぶと<br>「やるべき問題」だけ | テスト範囲を選べば、今夜やるべき問題だけが、一覧になります。 |
| 30–36 s | Logo card: Lens Snap / 視点レンズ, arrow up toward channel name | 先行登録受付中（無料）<br>チャンネルページのリンクから | いま、無料で先行登録を受け付けています。チャンネルページのリンクから、どうぞ。 |

**Title (≤40):** テスト前の夜「何を復習すればいい？」に答えるには（24字）

宿題・ドリル・返ってきたテストを撮っておくだけで、テスト前には間違えた問題だけの一覧ができる道具「Lens Snap」を準備しています。
小学生・中学生の算数・数学から。先行登録（無料）はこちら → https://snap.domo-ai.com/?src=yt
